# asdf-dtctl

Plugin de [asdf](https://asdf-vm.com/) para instalar [dtctl](https://github.com/Dynatrace/dtctl).

## Uso

```bash
# Desde ruta local
asdf plugin add dtctl /home/carlos/work/asdf-dtctl

# O desde repositorio Git (cuando lo publiques)
asdf plugin add dtctl <URL_DEL_REPO>

asdf list all dtctl
asdf install dtctl latest
asdf global dtctl latest
dtctl version
```

## Plataformas soportadas

- Linux amd64/arm64
- macOS amd64/arm64
